# Security

This is a synthetic portfolio demonstration. The public frontend sandbox makes no API/model calls. The local Django API is intended for one developer on localhost and must not be exposed as a production service without authentication, rate limits, secure deployment settings and a retention policy.

Keep `OPENAI_API_KEY` on the server; never put secrets in `VITE_` variables. Only original synthetic telemetry belongs in the repository. The application never executes remediation or generated code. Provider suggestions remain untrusted text even when citation and quotation checks pass.

Report a vulnerability privately to **travisvercueil@gmail.com** with reproduction steps. Do not include real credentials or customer data in an issue. There is no guaranteed response SLA for this portfolio project.
